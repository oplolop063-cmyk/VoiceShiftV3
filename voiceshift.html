Use with other apps

A web page or WebView app cannot replace the microphone used by Discord, LINE, games or other apps. Android does not let ordinary apps create a virtual microphone, and this version does not claim to. Options that do work:
  • Record in VoiceShift and send the audio file as a voice message.
  • Use a USB audio interface or hardware voice processor that feeds the other app.
  • Run VoiceShift on a second device and connect its headphone output to the first phone's microphone input with an audio cable and adapter.
The native Android engine (Oboe/AAudio) is not built yet. The APK currently wraps this web version.
